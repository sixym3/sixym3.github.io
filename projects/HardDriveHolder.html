Custom Hard Drive Holder

Completed Q3 2021

Custom 3D-printed solution for cryptocurrency mining - Multi-drive cooling system with modular design

Overview

A 3D-printed rack for running several 3.5″ drives continuously. Proof-of-space mining needs a lot of storage spinning at once, and during the mining boom commercial enclosures were both expensive and out of stock. I modelled one in SolidWorks instead, designed around airflow and easy expansion.

Design notes

Thermal

Drives sit spaced for a clear front-to-back path to a 120 or 140 mm case fan, so heat does not pool between them and throttle the array.

Modular

Each section stacks, so the rack grows with the number of drives instead of being replaced.

Fit

Mounting holes match the standard 3.5″ SATA pattern, so drives use ordinary case screws.

Built with

SolidWorks 3D Printing PLA Thermal Design
