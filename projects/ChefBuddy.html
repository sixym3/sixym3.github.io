ChefBuddy

In Development

AI-powered recipe manager inspired by Paprika V3 - Smart meal planning with automated pantry tracking

Overview

A recipe manager that does the tedious parts itself. Existing apps scrape recipes off the web and misfile the results, so you end up correcting ingredient lists by hand. ChefBuddy runs scraped pages through a language model to extract and summarise them properly, then plans meals and tracks what is actually in your pantry.

What it does

Recipe capture

Cheerio pulls the page, the OpenAI API turns it into structured fields. That fixes the misclassification that made the manual cleanup necessary in the first place.

Meal planning

Suggests plans from stated preferences and what is already in the pantry.

Pantry from receipts

OCR on a photographed grocery receipt updates stock, and flags ingredients that are missing or past their date.

Versioned schema

Recipes are stored against a versioned JSON schema, so changing how the model extracts data does not invalidate everything already saved.

Built with

Vue.js Express.js Node.js OpenAI API Cheerio OCR JSON Schema
