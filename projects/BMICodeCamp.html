Biomedical ML Bootcamp

Completed Fall 2023

Biomedical Data Analytics & Machine Learning Bootcamp - Stony Brook Medicine & CEAS Department intensive program

Overview

An intensive machine learning bootcamp run by Stony Brook Medicine and the College of Engineering in Fall 2023, applying supervised and unsupervised methods to biomedical data.

What I worked on

Classification

Decision trees and random forests, then PyTorch networks where I tuned layer depth and width against validation performance rather than guessing.

Clustering and features

K-means evaluated with silhouette scores, and SelectKBest to cut features down to the ones carrying signal.

Tuning and vision

Optuna for automated hyperparameter search, plus OpenCV edge detection with hand-written convolution kernels.

Built with

Python PyTorch Scikit-learn Pandas NumPy OpenCV Optuna Seaborn
