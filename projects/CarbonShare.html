CarbonShare

Prototype Completed

Decentralized Carbon Tracking Solution - Blockchain-powered sustainability rewards with ERC-20 tokens

Overview

CarbonShare rewards people for travelling with a lower carbon footprint. The idea came from Yun Zhang, CEO of Mobileware, who wanted users of his carpool app to earn something verifiable for the emissions they avoid. We built it as ERC-20 tokens on Ethereum, so a company or an individual can point at an on-chain record instead of a self-reported number.

How it works

Ride data

Trips are filtered and stored in MongoDB Atlas, which keeps the aggregate queries fast as the number of users grows.

API

A Flask REST API aggregates ride and reward data for the dashboard, and bridges the blockchain side to ordinary web services.

Smart contract

A microservice checks rides for reward eligibility and calls the contract on the Sepolia testnet to issue CarbonShare Tokens.

Dashboard

The front end shows rides, rewards and a live token balance.

Built with

Solidity ERC-20 Truffle Web3.py Python Flask MongoDB Atlas Ethereum
